# RAT TIDE / 机械怒潮 (v2.0 Cloudflare Enhanced Edition)

驾驶一艘锈迹斑斑的拖网渔船，在被机械海兽占领的怒潮海域里灵活航行、自动索敌反击、自动磁吸拾荒、强化升级，并活到下一次涨潮。鱼群随航行时间增加，让海面逐渐热闹起来。

本项目是基于 **Three.js + TypeScript** 打造的第三人称海战生存游戏，已针对 **Cloudflare Pages / Workers** 部署进行了完整预构建与优化。

**在线游玩：** [https://my-fishing-boat.pages.dev/](https://my-fishing-boat.pages.dev/)

游戏页面首次打开时会检查新版本，之后每 24 小时检查一次；发现新版后会提示刷新，避免打断正在进行的航程。

## v2.0 核心新增与优化特性

1. **智能火控系统（自动攻击 & 自动反击）**
   - **自动攻击（快捷键 `F` 或 HUD 按钮切换）**：自动扫描并锁定 145m 射程内的机械海兽，结合弹道飞行时间与海兽移速进行预判瞄准并自动开火。按住鼠标左键或空格可随时手动接管。
   - **自动反击（快捷键 `G` 或 HUD 按钮切换）**：当渔船遭受近战撕咬或远程墨弹袭击时，火控系统立即将袭击者标记为最高优先级反击目标，并触发快速反击装填（缩短当前冷却），瞬间向攻击源还击。
2. **手动转向与自由环视**
   - 船头默认不跟随鼠标；鼠标用于瞄准，按 `A` / `D` 手动打舵。可用 `M` 或 HUD 按钮开启可选鼠标转向。
   - **360° 自由环绕镜头与全向炮塔**：解除镜头水平旋转角度限制，右键拖动可 360° 无死角环视；修复炮塔跨船尾 ±180° 边界时的最短弧插值，实现丝滑 360° 旋转瞄准。
3. **技能点每秒自动 +10 & 热力值每秒自动 +3%**
   - **技能点数被动增长**：航行期间每秒自动获得 **10 点技能点**，升级时另获 1 点。所有技能都可无限加点；通过左侧技能下拉菜单或 `U` 打开技能窗。
   - **热力核心被动充能**：热力值每秒自动增加 **3%**，配合命中海兽额外充能；达到 100% 自动触发 **热力觉醒**，秒杀 30 米范围内所有机械海兽。
4. **休闲难度与渐进鱼群**
   - 降低海兽伤害与成长速度。开局最多同时出现 2 只海兽，此后每 90 秒增加 1 只，最多 6 只；鱼群随时间增加，生成间隔也会逐渐缩短。
5. **新增「动力（移动速度）」加点选项**
   - 强化面板包含 **动力 (`power`)**：每级提升 **+12% 移动速度**，同步提升前进/倒车加速度与转向推力。
6. **靠近物品自动磁吸拾起 & 海上补给箱打捞**
   - 渔船靠近海上漂浮战利品（24m 内触发磁吸牵引，12.5m 内自动收入船舱），无需手动按 `E` 键。
   - 海上漂浮的 GLB 补给箱现已支持靠近自动打捞，直接爆出金属零件、柴油、淡水并奖励 XP。
   - 新增 **一键整备（快捷键 `H`）**：自动按需使用背包内的绷带、止痛药、金属零件、柴油、淡水与生肉。
7. **浏览器语言与界面字体**
   - 根据浏览器首选语言显示中文或英文（英语浏览器使用英文，其余默认中文）；使用较大黑体优先的界面字体。
8. **TXT 文本存档导出与导入**
   - 支持将当前游戏进度一键导出为可读性良好的 `.txt` 文本文件（包含船长状态摘要与结构化存档块）。
   - 在主菜单、顶部战术栏、暂停菜单、阵亡结算页均可随时通过 **选择本地 `.txt` 文件** 或 **粘贴 `.txt` 文本内容** 恢复存档。

## 部署到 Cloudflare 指南

本项目已完成生产环境预构建（`dist/` 目录内已包含完整的静态产物与 `_headers` 缓存配置），提供以下 3 种部署方式：

### 方式一：Cloudflare Pages 网页端直接上传 `dist`（最快，零配置）

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> 进入 **Workers & Pages**。
2. 点击 **Create** -> 选择 **Pages** 标签页 -> 点击 **Upload assets**（直接上传静态文件）。
3. 输入项目名称（`my-fishing-boat`），将本项目中的 **`dist` 文件夹** 直接拖拽上传并点击 **Deploy site** 即可立即上线。

### 方式二：使用 Wrangler CLI 一键部署

首次部署时先创建 Pages 项目，再上传构建产物：

```bash
npx wrangler@4.78.0 pages project create my-fishing-boat --production-branch main
npx wrangler@4.78.0 pages deploy dist --project-name my-fishing-boat --branch main
```

后续部署只需再次运行第二条命令。

### 方式三：连接 GitHub / GitLab 自动构建部署

1. 将本项目推送至 GitHub / GitLab 仓库。
2. 在 Cloudflare Pages 中选择 **Connect to Git** 并关联仓库：
   - **Framework preset**: `None` 或 `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
3. 项目根目录已内置 `.node-version` (`22.12.0`) 与跨版本构建脚本 `scripts/build-bundle.mjs`，在 Node 18 / 20 / 22 环境下均可稳定完成构建。

## 操作一览

| 按键 / 输入 | 功能 |
| --- | --- |
| `W` / `S` | 前进油门 / 减速倒车 |
| `鼠标移动` | 主炮瞄准 |
| `A` / `D` | 手动左舵 / 右舵 |
| `F` | 切换 **自动攻击**（开启/关闭） |
| `G` | 切换 **自动反击**（开启/关闭） |
| `M` | 切换可选的鼠标船体转向（默认关闭） |
| `H` | **一键整备**（智能使用背包物资修复/止血/加油/饮食） |
| `鼠标左键` / `空格` | 手动开炮连射 |
| `鼠标右键拖动` / `滚轮` | 360° 环绕观察视角 / 缩放镜头距离 |
| `靠近漂浮物` | 自动磁吸拾取入舱 |
| `Tab` | 打开 / 关闭船舱与背包 |
| `U` | 打开渔船技能面板（技能点每秒 +10，无等级上限） |
| `1` – `7` / `R` | 快捷使用补给 / 快捷维修 |
| `Esc` | 暂停菜单 / TXT 存档导入导出 |
